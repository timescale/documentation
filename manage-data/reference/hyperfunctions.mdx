import { TIMESCALE_DB, TOOLKIT_LONG, CLOUD_LONG } from '/snippets/vars.mdx';

{CLOUD_LONG} includes all hyperfunctions by default, while self-hosted {TIMESCALE_DB} includes a subset of them. For
additional hyperfunctions, install the [{TOOLKIT_LONG}][install-toolkit] extension.

## Available hyperfunctions

Here is a list of all the hyperfunctions provided by {TIMESCALE_DB}. Hyperfunctions with ✓ in the `Toolkit` column
require an installation of {TOOLKIT_LONG} for self-hosted deployments. Hyperfunctions with ✓ in the `Experimental`
column are still under development.

<Info>
Experimental hyperfunctions are still under active development and subject to change. When you upgrade to a new
version of {TOOLKIT_LONG}, experimental features might have changed or been removed. Be prepared to update your code
if you use experimental hyperfunctions.
</Info>

| Hyperfunction | Description | Toolkit | Experimental | Family |
|---------------|-------------|---------|--------------|--------|
| [`asap_smooth()`][asap_smooth] | Downsample data with the ASAP smoothing algorithm | ✓ | | Downsampling |
| [`candlestick_agg()`][candlestick_agg] | Aggregate financial candlestick data | ✓ | | Financial analysis |
| [`compact_state_agg()`][compact_state_agg] | Compact representation of state changes | ✓ | | State tracking |
| [`counter_agg()`][counter_agg] | Aggregate counter data with reset handling | ✓ | | Counters and gauges |
| [`count_min_sketch()`][count_min_sketch] | Probabilistic counting with count-min sketch | ✓ | ✓ | Sketching |
| [`days_in_month()`][days_in_month] | Get number of days in a month | | | Time-series utilities |
| [`first()`][first] | Get the first value in a time range | | | Time-series utilities |
| [`freq_agg()`][freq_agg] | Track frequency of values | ✓ | | Frequency analysis |
| [`gauge_agg()`][gauge_agg] | Aggregate gauge metrics over time | ✓ | | Counters and gauges |
| [`gp_lttb()`][gp_lttb] | Downsample with LTTB (Greenplum version) | ✓ | ✓ | Downsampling |
| [`heartbeat_agg()`][heartbeat_agg] | Track system liveness from timestamped heartbeats | ✓ | | State tracking |
| [`histogram()`][histogram] | Approximate distribution with histogram | | | Distribution analysis |
| [`hyperloglog()`][hyperloglog] | Probabilistic cardinality estimation | ✓ | | Sketching |
| [`interpolate()`][interpolate] | Linear interpolation for missing values | | | Gapfilling |
| [`last()`][last] | Get the last value in a time range | | | Time-series utilities |
| [`locf()`][locf] | Last observation carried forward | | | Gapfilling |
| [`lttb()`][lttb] | Downsample with Largest Triangle Three Buckets | ✓ | | Downsampling |
| [`max_n()`][max_n] | Get N largest values | ✓ | | Top-N analysis |
| [`max_n_by()`][max_n_by] | Get N largest values by a specific column | ✓ | | Top-N analysis |
| [`min_n()`][min_n] | Get N smallest values | ✓ | | Top-N analysis |
| [`min_n_by()`][min_n_by] | Get N smallest values by a specific column | ✓ | | Top-N analysis |
| [`month_normalize()`][month_normalize] | Normalize intervals to months | | | Time-series utilities |
| [`saturating_add()`][saturating_add] | Addition with saturation at bounds | ✓ | | Saturating math |
| [`saturating_add_pos()`][saturating_add_pos] | Positive addition with saturation | ✓ | | Saturating math |
| [`saturating_multiply()`][saturating_multiply] | Multiplication with saturation | ✓ | | Saturating math |
| [`saturating_sub()`][saturating_sub] | Subtraction with saturation | ✓ | | Saturating math |
| [`saturating_sub_pos()`][saturating_sub_pos] | Positive subtraction with saturation | ✓ | | Saturating math |
| [`state_agg()`][state_agg] | Track state transitions over time | ✓ | | State tracking |
| [`stats_agg()`][stats_agg] | Statistical aggregate (one variable) | ✓ | | Statistical analysis |
| [`stats_agg()`][stats_agg_two] | Statistical aggregate (two variables) | ✓ | | Statistical analysis |
| [`tdigest()`][tdigest] | Percentile approximation for extreme percentiles | ✓ | | Percentile approximation |
| [`time_bucket()`][time_bucket] | Bucket time values into intervals | | | Time-series utilities |
| [`time_bucket_gapfill()`][time_bucket_gapfill] | Fill gaps in time-series data | | | Gapfilling |
| [`time_weight()`][time_weight] | Calculate time-weighted averages | ✓ | | Time-weighted calculations |
| [`uddsketch()`][uddsketch] | Percentile approximation with error guarantees | ✓ | | Percentile approximation |
